## 왜 평일 대기
야간선물(18~05시)·나스닥 선물(미국장)은 **장이 열려야 실데이터가 나옴**. 토요일 휴장이라 오늘은
코스피200 선물(정규장)만 마지막 종가로 확인됨. 검증 없이 blind 빌드 금지(fixture-trap).

## 검증된 것 (2026-07-19 라이브)
- **코스피200 선물 목록+시세**: `GET /uapi/domestic-futureoption/v1/quotations/display-board-futures`
  TR `FHPIF05030200`, params `{FID_COND_MRKT_DIV_CODE:"F", FID_COND_SCR_DIV_CODE:"20503", FID_COND_MRKT_CLS_CODE:"MKI"}`
  → output 행: `futs_shrn_iscd, hts_kor_isnm(예 "미니F 202608"), futs_prpr(현재가), futs_prdy_ctrt(등락률),
  prdy_vrss_sign, acml_vol, futs_askp/bidp`. **한 콜에 시세까지** 다 옴(inquire-price 불필요).
  - MKI = **미니** 코스피200 선물. 정규(대형) 선물의 cls 코드는 평일 재확인(다른 값 시도: "" 등).
    → **①에서 확정: `""`(빈 문자열)이 정규/대형이었다.** 아래 ① 항목 참조.
  - 월물 선택 = **거래량(acml_vol) 최다** 행(최근월물). 코드는 월물마다 바뀜(롤오버) → 매번 board로 재해결.
- 개별 현재가 TR: `inquire-price` `FHMIF10000000` `{FID_COND_MRKT_DIV_CODE:"F", FID_INPUT_ISCD:<code>}`
  (board가 시세를 줘서 보조용).

## 설계 (표시 위치)
<!-- 아래는 2026-07-19 초안이다. 실제 설계·구현은 2026-07-31 스펙
     (docs/superpowers/specs/2026-07-31-index-futures-design.md)에서 다시 잡혔다 — 셋을
     한 줄에 나란히 벌리는 대신 "K200 칩"(주간↔야간 자동 전환) + "나스닥 칩" 2개로 합쳤다.
     아래 항목은 폐기가 아니라 이력으로 남긴다. -->
- 대시보드 상단 **"📊 선물" 라인**(기존 지수 라인 옆/아래), **시간대 적응**:
  - KR 장중 → 코스피200 선물(현재가·등락%).
  - KR 야간(18-05) → 야간선물.
  - 미국 시간대 → 나스닥 선물(지연 배지).
- 셋을 한 줄에 나란히 보여도 됨(공간 되면): `코스피선물 ▲ · 야간 ▲ · 나스닥선물 ▼(지연)`.
- 파서/조립: `backend/flow/futures.py`(신설, 순수 파서 + KisClient 메서드) → `marketdata.get_futures()` (TTL 캐시)
  → `/api/futures` → 대시보드 렌더. **각 단계 라이브 검증 후 커밋**(코스피→야간→나스닥 순).
- 연계 확장(후순위): 야간선물·나스닥 선물을 **내일예상(nextday) 신호로 추가** — 가장 직접적 시초가 예측.

**실제로 나간 것(shipped)**: 기존 지수 칩 스트립에 칩 2개 — `k200`(주간↔야간 자동 전환,
마감/지연 배지) · `nq`(나스닥 QQQ, `$` 표기, 지연 배지). 칩별 독립 캐시라 한쪽 소스 실패가
다른 칩을 비우지 않는다. 2026-08-03 09:11 KST 라이브 종단 검증:
`k200 = A01609 "F 202609" 995.9 −3.37% session=day`, `nq = 나스닥 QQQ 687.99 +0.65%`.

알려진 의도적 편차(리뷰에서 발견하고 이번 범위에서 보류하기로 한 것 — 누락 아님):
- 스펙의 세션표는 나스닥 칩도 정비시간에 "마감"을 붙이는 것으로 적혀 있었으나, 실제로는
  K200 칩만 마감 배지를 받고 나스닥 칩은 항상 "지연"만 표시한다. 미국 장 시간이 한국 세션과
  달라 나스닥 칩의 "마감"이 무엇을 뜻해야 하는지는 아직 결정하지 않았다.
- K200 칩은 캐시 히트 시 `label`/`session`이 그 값을 처음 저장한 시점 기준으로 남는다 —
  06:00 야간→마감 전환 순간엔 TTL 한 창(최대 5분, 하루 1회)만큼 라벨이 늦을 수 있다.
  마감 배지 자체는 매 요청 재계산이라 항상 정확하다.

자세한 설계 근거는 2026-07-31 스펙 §검증 게이트·§WsSession 참조.

## 안전/제약
- REST·캐시토큰·웹소켓 미접촉(야간 WS는 쓰지 않음, ②가 REST 불가로 나오기 전까지) · Python 3.9 ·
  실시간 재배포 금지(개인용).
- 나스닥은 선물이 아니라 QQQ ETF 프록시로 나갔지만(③ 참조), 지연 시 "지연" 표기 원칙은 그대로
  지켰다(오인 방지).
