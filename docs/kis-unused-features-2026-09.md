## 2. 종목 상세(`/live/{코드}`)에 붙일 것

### 2-1. 예탁원 일정 7종 ⭐⭐⭐ — 지금 앱엔 없다(용어집에만 '배당락' 설명)

|---|---|---|
| ksdinfo_dividend 배당일정 | HHKDB669102C0 | 기준일·배당종류·현금배당금·현금배당률·지급일·**고배당종목여부** |
| ksdinfo_paidin_capin 유상증자 | HHKDB669100C0 | 기준일·발행할주식·확정배정율·할인율·발행예정가·**권리락일**·청약기간 |
| ksdinfo_bonus_issue 무상증자 | HHKDB669101C0 | 확정배정율·권리락일·상장일 |
| ksdinfo_sharehld_meet 주주총회 | HHKDB669111C0 | 주총일자·사유·의안 |
| ksdinfo_rev_split 액면교체 | HHKDB669105C0 | 변경 전후 액면가·**매매거래정지기간** |
| ksdinfo_merger_split 합병·분할 | HHKDB669104C0 | 상대 회사·비율·매매거래정지기간 |
| ksdinfo_purreq 주식매수청구 | HHKDB669103C0 | 매수청구가격·접수시한 |
| (그 외) 감자·상장·공모주청약·실권주·의무예치 | HHKDB669106~110C0 | 관심종목엔 드묾. 공모주청약은 홈 캘린더용으로 쓸 만하다 |

- **입력**: 기간 `f_dt`~`t_dt` + 종목 `sht_cd`. 종목을 비우면 시장 전체가 오는지는 프로브로 확인.
- **어떻게**: 종목 상세 헤더 아래 "📅 다가오는 일정" 칩(D-n). 홈에는 관심종목 전체를 모은 2주 캘린더.
- **초보 번역**: 배당은 "기준일 **2영업일 전**까지 사야 받는다", 유상증자는 "주식 수가 늘어 내 몫이 희석, 권리락일에 주가가 기계적으로 조정", 액면분할·합병은 "며칠 거래 정지 — 그때 팔 수 없다".
- **비용**: 관심종목 20개 × 7콜 = 140콜/일, 캐시 24h. 유량 무관.

### 2-2. 증권사 투자의견·목표가 ⭐⭐⭐ — 지금 앱엔 없다
- `invest_opinion` FHKST663300C0: 기간별 투자의견·직전 의견·**HTS목표가격**·N일 괴리율·선물괴리도.
- `invest_opbysec` FHKST663400C0: **증권사별** 의견·목표가.
- **어떻게**: '기업 체력' 라인에 "목표가 평균 n원 · 현재가 대비 -18% · 최근 하향 2건". 상향/하향 전환 시 뉴스 칩과 같은 톤.
- **초보 번역**: 목표가는 예언이 아니라 증권사의 희망이다. 숫자보다 "**방향이 바뀌었나**"(상향→하향)가 신호.
- **주의**: 리서치 자료라 개인 화면 전용(재배포 금지는 시세와 같은 결).

### 2-3. 매물대·거래비중 ⭐⭐ — 지금 앱엔 없다
- `pbar_tratio` FHPST01130000: 가격대(데이터순위)별 체결거래량·누적거래량비중 + **가중평균주식가격**.
- **어떻게**: 가격 차트 오른쪽에 가로 막대(매물대). "가장 두꺼운 가격 n원 = 지지·저항 후보" 한 줄. 감시선 추천값으로도 쓸 수 있다.
- **비용**: 장중 5분 캐시 1콜.

### 2-5. 일별 확정 추이 2종 ⭐⭐ — 지금은 '오늘'만 있다

- **어떻게**: 각 패널에 20일 스파크 + "프로그램 5일 연속 순매수", "최근 5일 중 4일 사자 우위".

### 2-6. 체결금액별 매매비중 ⭐⭐ — 현재 패널의 추정을 확정치로

- **주의**: 구간 정의(1천만 이상 등)와 갱신 주기는 프로브로 확인.

### 2-7. 종목별 일별 대차거래추이 ⭐ — 대차잔고의 KIS 대안(세 번째 원천)
- `daily_loan_trans` HHPST074500C0: 일자별 **당일 증가(체결)·감소(상환)·대차거래 증감·잔고 주수·잔고 금액** + 종가. 기간 1콜(`cts`로 연속).
- 현재 대차잔고는 토스(0차, `SM_TOSS_*` 설정됨) → 금투협 → 예탁결제원 순. 빈자리가 아니라 **토스의 "토큰 client당 1개" 함정이 없는 대안**이다. 같은 KIS 키·REST라 1키1세션과 무관.
- **주의 ①** `flow/shortbal.py`는 원천이 다르면 전일 대비를 계산하지 않는다(집계 범위 차이 실측 14.1M vs 11.1M주). 붙이면 행마다 출처 태그 필수.
- **주의 ②** 공식 예제는 `mrkt_div_cls_code="1"`(코스피)에 종목코드를 함께 넘기는데 파라미터 설명은 3=종목이다. 어느 쪽이 맞는지 **프로브 1콜로 확인**해야 한다.

- **트레이드오프**: FDR 경로는 KIS 키 없이도 차트가 뜨게 하려고 고른 것(데모 모드·미국 티커와 같은 경로). KIS로 바꾸면 국내 차트가 키에 의존한다 — 키 없을 때 FDR 폴백을 남기면 된다. 콜 수: 일봉 120 = 2콜, 주봉 15년 ≈ 8콜, 월봉 2콜, 캐시 1시간.
