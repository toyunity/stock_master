# 홈 위젯 — 설치·사용 가이드(아이폰 · 갤럭시)

> ⚠ **공유 금지 — 이제 토큰은 자산 정보를 지키는 키입니다.**
> 위젯에는 관심종목 시세뿐 아니라 **보유 수량·평균매입가로 계산한 손익(수익 금액·수익률)** 이 표시됩니다.
> 이 토큰(그리고 토큰이 보이는 /widget-setup 화면)을 타인과 공유하면
> ① KIS 시세를 제3자에게 제공(약관 위반)일 뿐 아니라 ② **내 보유·손익이 그대로 노출**됩니다.
> 스크립트 파일 자체엔 토큰이 없어 안전하지만, 토큰은 절대 밖으로 보내지 마세요.

> **계정별 토큰**: 토큰은 로그인한 계정마다 다릅니다. 각 사용자는 **자기 계정으로 로그인해**
> `/widget-setup`에서 자기 토큰을 발급받아 설치하세요. 내 위젯은 내 관심종목·보유·손익만 봅니다
> (다른 계정 데이터는 어떤 경우에도 보이지 않습니다).

## 아이폰 설치 (5단계, 약 5분)

1. **App Store에서 “Scriptable” 설치** (무료 — 개발자 계정·컴퓨터 불필요)
2. **아이폰 사파리로 `https://<내-머신>.ts.net/widget-setup` 접속**
   — 평소처럼 **본인 계정으로** 구글 로그인 + 2FA. 그 계정 전용 토큰과 스크립트가 준비되어 있습니다.
3. **[스크립트 전체 복사] → Scriptable 앱 → ＋ → 붙여넣기 → 이름 `StockMaster`로 저장
   → ▶ 실행 → [토큰 복사]한 값 붙여넣기(1회)** — 토큰은 아이폰 Keychain에 저장됩니다.
4. **홈 화면 길게 누르기 → 왼쪽 위 ＋ → Scriptable 검색 → 크기 선택 → 추가**
   — 기본은 **중간(4×2)**. **보유 종목이 많으면 큰 위젯을 권장**합니다(아래 “위젯 크기” 참고).
5. **추가된 위젯 길게 누르기 → 위젯 편집 → Script: `StockMaster` 지정**
   — ⚠ 이 단계를 빼먹으면 “Tap to configure”로 남습니다(가장 흔한 실수).

## 갤럭시(안드로이드) 설치 (5단계, 약 5분)

갤럭시는 Scriptable이 없어 **위젯 전용 앱**을 설치합니다(앱은 서버의 `/api/widget`만 읽고, PWA는 지금처럼 브라우저로 씁니다).

1. **폰 브라우저로 `https://<내-머신>.ts.net/widget-setup` 접속** — 본인 계정으로 구글 로그인 + 2FA.
2. **[APK 다운로드] → 열기 → “출처를 알 수 없는 앱” 허용(브라우저에 1회) → 설치.**
   버튼이 없고 “APK가 아직 없어요”가 보이면 맥에서 `make android`를 먼저 실행합니다.
3. **[앱에 자동 입력] 탭** → 위젯 앱이 열리며 서버 주소·토큰이 저장되고 “연결 OK · N종목”이 뜹니다.
   안 열리면 앱을 직접 열어 [토큰 복사] 값을 붙여넣고 [저장하고 연결 확인].
4. **앱의 [홈 위젯 추가]** → 확인 → 홈에 위젯이 놓입니다. **커버 화면과 메인 화면은 홈이 따로**라 각각 한 번씩.
   (수동: 홈 길게 누르기 → 위젯 → Stock Master 위젯.) 크기는 원하는 대로 늘려도 됩니다 — 행 수가 높이에 맞춰 바뀝니다.
5. **절전 예외 등록(빼먹으면 며칠 뒤 갱신이 멈춥니다)** — 앱의 **[배터리 제한 해제]**(시스템 대화상자 → 허용) 그리고
   **설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱 → “Stock Master 위젯” 추가.**
   One UI는 안 여는 앱을 자동으로 잠들게 하는데, 위젯 앱은 원래 열지 않는 앱이라 정확히 그 대상입니다. 펌웨어 업데이트 뒤 목록을 다시 확인하세요.

**업데이트**: 같은 페이지에서 새 APK를 내려받아 설치하면 덮어써집니다(같은 서명). 토큰 재입력은 필요 없습니다.

## 사용법

위젯은 종목마다 최대 2줄로 보여줍니다. 보유(수량·평균매입가)가 있으면 손익 줄이 추가됩니다.

| 동작 | 결과 |
|---|---|
| 위젯 보기(1줄) | 종목명·현재가·등락률 (**상승 빨강↑ / 하락 파랑↓**) |
| 위젯 보기(2줄) | 보유 종목은 아래에 **`N주` · 수익 금액 · 수익률** 추가(같은 상승빨강/하락파랑 색규칙) |
| 미국 종목 | 티커+한글명, 현재가 `$`(소수 2자리)로 표시 |
| 위젯 몸통 탭 | Stock Master 앱(사파리) 열림 |
| **↻ 갱신 탭** | Scriptable이 열리며 **즉시 실시간 시세 표** 표시(위젯 숫자는 다음 자동 갱신 때 반영 — iOS 제약) |
| “HH:MM 장중” | 장중 KIS 실시간 현재가 기준 시각 |
| “7/15(화) 마감” | 장외 — 해당 거래일의 마감값(NXT 애프터장 반영값일 수 있음) |
| “오프라인 · …” | 서버(맥북)에 연결 실패 — 마지막 저장값 표시 중 |

- **갤럭시 위젯의 ↻ 갱신은 즉시 반영**됩니다(수 초 안에 숫자가 바뀜 — iOS와 다른 점). 몸통 탭은 PWA를 엽니다.
  자동 갱신은 장중 15분·장외엔 다음 개장까지 잠들며, 맥이 잠자면 “오프라인·”이 붙습니다.
- **갱신 주기**: iOS가 정합니다(대략 15분+, 밤·주말엔 다음 개장까지 잠듦).
  실시간 티커가 아니라 “쓱 보는 근사치”입니다. 지금 값이 필요하면 ↻ 갱신을 탭하세요.
- **맥북이 잠자면** 위젯도 새 값을 못 받습니다 — “오프라인” 표시로 알 수 있습니다.
- **손익 표시**는 내가 입력한 보유 수량·평균매입가 기준의 **참고 근사치**입니다(수수료·세금·환율 제외).
  미국 종목의 손익은 달러 기준입니다.

## 위젯 크기 — 보유가 많으면 큰 위젯

- 위젯은 세로 공간에 들어가는 만큼만 그리고, 넘치면 마지막 줄에 **“+N종목”** 으로 접습니다(잘림 경고 없이 사라지지 않음).
- **중간(4×2)**: 2줄 항목 기준 대략 2~3종목까지 편안합니다.
- **큰(4×4)**: 대략 6~7종목까지. **보유 종목이 많거나 손익 줄이 붙는 종목이 많으면 큰 위젯**을 쓰세요.

## 미국 주식

- 관심종목에 **미국 종목(예: `NVDA`, `AAPL`)** 을 담을 수 있습니다. 위젯엔 `$` 가격·등락률·(보유 시) 달러 손익이 표시됩니다.
- **담는 법**: 대시보드 검색창에 **대문자 티커**(1~5자, `BRK.B` 같은 `.접미`도 가능)를 입력하면
  **“＋담기(US)”** 제안이 뜹니다. 담을 때 서버가 실제 거래소(NAS→NYS→AMS)에서 존재를 확인하고,
  없는 티커면 “티커를 찾을 수 없어요”로 거부합니다.
- 미국 종목은 **시세·위젯 전용**입니다 — 국내 분석 카드(수급·지표·뉴스 등 KR 전용 파이프라인)에는 나타나지 않습니다.

## 관심종목 관리 (검색·순서·삭제·보유 입력)

대시보드 상단 **“관심종목 관리”** 리스트에서 편집합니다 — 최대 10종목. 위젯·대시보드·MCP·리포트가 같은 목록을 봅니다.

- **추가**: 검색창에서 국내는 이름/코드로 **＋담기**, 미국은 대문자 티커로 **＋담기(US)**.
- **순서 바꾸기**: 행 왼쪽 **핸들(⠿)을 드래그**해 위아래로 이동. (버튼 `▲▼`으로도 항상 가능 — 드래그가 안 먹혀도 폴백 동작)
- **삭제**: 행을 **왼쪽으로 스와이프**(빨강 배경) 또는 **× 버튼**.
- **보유 입력**: 행의 **[보유]** 버튼 → **수량(정수)** 과 **평균매입가**(국내=원 정수 / 미국=$ 소수) 입력 → 저장하면 위젯에 손익이 뜹니다.
  - 수량·평균가를 비우면 시세만 보이고 손익 줄은 생기지 않습니다.

> 알려진 제약: 새로 담은 국내 종목은 뉴스 매칭에 회사명 1개(공식명)만 쓰여
> 약칭·영문명 기사가 안 잡힐 수 있어요. 기본 종목들은 수동 별칭이 튜닝돼 있습니다.

## 문제 해결

| 증상 | 조치 |
|---|---|
| “토큰이 맞지 않아요” / “응답 오류 — 토큰을 확인하세요” | Scriptable에서 스크립트 ▶ 실행 → **“토큰 다시 입력”** 선택 → 새 토큰 붙여넣기 |
| 위젯이 “Tap to configure” | 위젯 편집에서 Script: StockMaster 지정(설치 5단계) |
| 계속 “오프라인” | 맥북 서버 확인: `curl -s localhost:8000/healthz` → 필요 시 재기동(docs 서버 운영 메모) |
| **토큰 유출 의심** | `/widget-setup` 접속 → **[토큰 재발급]** 클릭. 이전 토큰은 **즉시 무효화**됩니다. 그다음 아이폰에서 스크립트 ▶ 실행 → “토큰 다시 입력”으로 새 토큰을 넣으세요. (계정별 토큰이라 내 계정만 회전됩니다.) |
| (갤럭시) 위젯이 며칠째 같은 시각 | 절전에 걸렸을 가능성 — 설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱에 있는지 확인(펌웨어 업데이트가 목록을 되돌리기도 함) |
| (갤럭시) “설정이 필요해요” | 앱을 열어 주소·토큰 입력(또는 /widget-setup의 [앱에 자동 입력]) |
| (갤럭시) APK 설치가 막힘 | 다운로드한 브라우저에 “출처를 알 수 없는 앱” 설치 권한 부여 → 다시 열기. 업데이트가 막히면 서명이 다른 것 — 삭제 후 재설치(토큰 재입력) |

## 실기기 검증 체크리스트 (마스터 수동)

배포 후 실제 아이폰에서 한 번 확인하세요 — 자동 테스트로는 못 잡는 부분입니다.

- [ ] 본인 계정으로 `/widget-setup` → 토큰 발급·설치, 위젯 표시 정상
- [ ] 관리 리스트: 핸들 **드래그 순서변경**, **좌 스와이프 삭제**(+ ▲▼·× 버튼 폴백), **[보유] 입력** 저장
- [ ] 위젯 **2줄**(수량·수익·수익률) 렌더, **상승빨강/하락파랑** 색, 종목 사이 **실선 구분**, 넘칠 때 **“+N종목”** 오버플로
- [ ] **미국 종목**(예: NVDA) 담기·$가격·달러 손익 표시
- [ ] **[토큰 재발급]** 후 구 토큰이 위젯에서 “토큰이 맞지 않아요”로 막히고, 새 토큰 재입력 시 복구
- [ ] (갤럭시) 커버·메인 양쪽에 위젯 표시, 크기 변경 시 행 수가 따라옴, 다크·라이트 색(상승 빨강/하락 파랑)
- [ ] (갤럭시) ↻ 탭 → 수 초 안에 갱신시각이 바뀜 · 몸통 탭 → PWA
- [ ] (갤럭시) [토큰 재발급] 후 위젯이 “토큰이 맞지 않아요”로 바뀌고, 앱에서 새 토큰 저장 시 복구
- [ ] (갤럭시) 절전 예외 등록 뒤 다음 날에도 갱신시각이 살아 있음 · 설정 → 배터리의 앱 사용량 1% 미만
