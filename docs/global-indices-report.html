대시보드에 접힌 '글로벌' 섹션이 생겼습니다. 미국채 2·10·30년 금리, WTI 유가, 금, S&P500·나스닥·VIX — 전부 정확한 단위로, 항목마다 기준일을 달고 뜹니다.

원천이 셋으로 갈린 건 설계가 게을러서가 아니라, 하나로 묶을 수 있는 원천이 없어서입니다. 아래에 그 근거가 전부 있습니다.

1. 야순지지는 어떻게 가져오나

프론트는 Next.js이고, 자기네 백엔드(/api/prices, socket.io)만 부릅니다. 상단 원천은 클라이언트 번들에 안 드러납니다. 다만 이 저장소에 이미 있던 docs/yasun-gg-teardown.md(07-30 실측)가 소스맵을 밝혀뒀고, 이번에 재확인했습니다.

3. 걸러낸 함정 셋 — 전부 "그럴듯한 숫자"였다

셋 다 오류를 내지 않습니다. 그냥 틀린 값이 조용히 나옵니다 — 이 프로젝트가 반복해서 데이던 실패 유형입니다.

② ETF 가격은 원자재 가격이 아니다

GLD는 실시간에 가깝고 방향(등락률)도 맞지만, 가격의 자릿수가 다릅니다. "금 402"를 야순 옆에 놓으면 그냥 틀린 숫자로 읽힙니다.

③ 금리 등락은 %가 아니라 bp다

10년물이 4.65 → 4.72로 움직였습니다. 상대변화율로 쓰면 +1.51%인데, 값 자체가 %인 유일한 그룹이라 "4.72% ▲1.51%"는 금리가 1.51%p 뛴 것으로 읽힙니다. 채권시장 관례도 bp입니다.

처음 구현4.72% ▲1.51%
고친 뒤4.72% ▲7bp

이건 워크플로우가 만든 코드에 남아 있던 것을 마지막 검토에서 잡아 고쳤습니다.

4. 구현
backend/flow/worldidx.py 세 원천 fetch · parse · 캐시 · 집계 (신규 465줄)
├ 재무부 XML TTL 1시간 실패 시 전월 폴백
├ FDR TTL 10분 심볼마다 개별 상한
└ KIS 지수 TTL 60초 semi.py SOX와 같은 경로
backend/api/app.py GET /api/worldidx (+13줄)
backend/report/dashboard.py '글로벌' 접힌 섹션 (+103줄)

설계에서 양보하지 않은 두 가지

  • 단위를 데이터에 실어 내린다 (unit·rate_unit). 프런트가 단위를 추측하기 시작하면 위의 함정이 렌더러에서 그대로 재발합니다.
  • 기준일도 항목마다 싣는다 (basis). 살아 있는 코스피 칩 옆에 놓이면 값이 신선해 보이는 착시가 생깁니다. 해외지수 기준일 폴백은 KST가 아니라 ET(주말은 금요일로 되감기) — 한국 아침에 KST 오늘을 찍으면 간밤 값에 오늘 날짜가 박힙니다.

적대적 검토가 잡은 결함 (high 2건)

  • FDR 무한 대기 — fdr.DataReader → requests.get에 timeout 인자가 아예 없습니다. 야후가 응답 없이 매달리면 락을 영구히 물어 글로벌 섹션 전체가 그 시각 스냅샷에 얼어붙습니다. 예외는 격리했는데 행(hang)은 격리가 안 돼 있었습니다. → 호출마다 8초 하드 상한 + 그룹 30초 백스톱.
  • 기준일이 미래로 — ET 날짜를 직전 거래일로 되감지 않아 월요일 아침엔 일요일 날짜가, 평일 낮엔 아직 열리지도 않은 오늘 날짜가 찍혔습니다. → 주말 되감기.

6. 토스증권 Open API — 별건 검토

공식 스펙 원문(openapi.json v1.2.13, 엔드포인트 33개)을 직접 받아 분석했습니다.

이번 건의 대안은 못 됩니다. Market Indicators의 심볼 카탈로그가 8종이 전부이고 전부 국내입니다 — KOSPI, KOSDAQ, KR_BOND_2Y~30Y. 카탈로그 밖은 400 unsupported-symbol. 미국채·금·유가·해외지수는 없습니다.

그래도 쓸 만한 것

  • 한국 국채 금리 2/3/5/10/20/30년 (% 단위) — 우리가 지금 어디서도 못 가져오는 데이터. 이번에 미국채를 넣었으니 나란히 두면 한·미 금리차가 한 화면에 보입니다.
  • 장 운영 캘린더 (KRX+NXT 통합) — futures.py에 "공휴일은 보지 않는다"는 한계가 주석으로 박혀 있는데, 이걸로 해소됩니다.

비용: 토스증권 계좌 필요 · 웹소켓 미지원(실시간은 계속 KIS) · 국채는 일봉만 · 두 번째 증권사 토큰 체계가 하나 더 생깁니다. 그래서 전면 도입이 아니라 KIS로 안 되는 이 2개만 선별 도입을 권합니다.

7. 남은 것 — 마스터 조치가 필요합니다
  • 8000 재기동 — 오늘 올린 두 커밋(차트 로딩 표시 87e8fe3, 글로벌 섹션 fe9f683)이 아직 화면에 안 떴습니다. 실서버는 오늘 10:03에 뜬 구버전입니다. 장 마감했으니 지금 재기동해도 안전합니다.
  • 해외선물 신청 (선택) — 한국투자증권에서 NYMEX·COMEX SUB거래소를 신청하시면, 지금의 FDR 경로를 KIS 실시간 선물로 승격할 수 있습니다. 코드는 이미 확보돼 있습니다(CLU26·GCQ26).
  • 토스 키 발급 (선택) — 한국 국채·장 캘린더를 하시려면 필요합니다.

같이 알아두실 것 — 아직 안 고친 결함

오늘 조사 중에 별도로 발견한 것으로, 마스터가 "지금은 안 고침"을 선택하신 건입니다: NXT 미상장 종목(411060 등)의 실시간 체결이 안 옵니다. _ws_fallback이 "연결됨"이면 REST 폴백을 건너뛰는데, 웹소켓이 연결됐지만 조용한 상태가 설계에 없습니다. 화면엔 "체결 대기 중"이 안 풀립니다.
