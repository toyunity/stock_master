# PWA 6차 리디자인 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** kospinow 모티브로 Stock Master PWA의 시각 문법을 재구성한다 — 토큰 톤, 근거 레일, 상대시간, 히어로 승격.

**Architecture:** `backend/report/theme.py`의 `BASE_CSS`가 6화면의 CSS 단일 출처다. 토큰과 공통 컴포넌트만 바꾸면 화면 파일을 안 건드려도 전부 따라온다. 페이지 파일은 *새 구조가 필요한 곳*만 손댄다. 4단계로 끊어 단계마다 브랜치 → `main` 병합.

**Tech Stack:** Python 3.9 · FastAPI · 자기완결 HTML(외부 CDN 0) · lightweight-charts(동봉) · pytest + node 렌더 스모크 + 헤드리스 크롬 캡처

## Global Constraints

설계 문서 `docs/superpowers/specs/2026-08-12-pwa-6차-리디자인-design.md`와 `CLAUDE.md`에서 그대로 옮긴다. **모든 태스크에 적용된다.**

- **포트 8000 실서버를 죽이거나 재기동하지 마라.** 마스터의 실서비스가 거기 떠 있다. 재기동이 필요하면 마스터에게 먼저 묻는다.
- **KIS를 건드리지 마라.** 검증 서버는 항상 `SM_FLOW_MODE=demo`. 토큰 재발급 금지(발급 시 마스터 폰으로 알림톡이 간다).
- **Python 3.9 문법만.** `match` 금지, `X | Y` 타입힌트 금지(`Optional[X]` 사용), 모듈 맨 위 `from __future__ import annotations`.
- **인터프리터는 `.venv/bin/python`.** 시스템 python3는 의존성이 없어 죽는다.
- **새 추상화·새 의존성·프레임워크 교체 금지.** 구현 1개짜리 인터페이스/팩토리 금지.
- **CSS 단일 출처는 `backend/report/theme.py`.** 페이지 파일에 색을 직접 쓰지 마라.
- **`/live` 패널을 DOM에서 제거하지 마라.** `render()`가 매 틱 `getElementById`를 146곳 돈다.
- **렌더 템플릿 `.replace()` 치환 순서.** 사용자·RSS 데이터를 자산(`__LIB__`, `__BASE_CSS__` 등)보다 먼저 치환하면 데이터에 섞인 자리표시자가 차트 라이브러리를 JSON 안에 주입해 페이지 JS가 전멸한다.
- **실측한 사실은 날짜와 함께 주석에 남긴다.**
- **개인 값(호스트명·가격 목표·계좌)을 소스 기본값에 박지 마라.**
- **화면(HTML/JS)을 고쳤으면 `make verify`까지 돌린다.**
- **`make eval`은 통과해야 정상이다.** 판정 문구 골든이라 디자인 작업으로 깨지면 디자인이 문구를 건드렸다는 신호다. `make eval-update`로 덮지 말고 원인을 찾는다.
- **무엇을 만들기 전에 `grep -rn "<이름>" backend/report/*.py`.** 이 스펙은 초안에서 "신설"이라 적은 것 중 **다섯 개가 이미 구현돼 있었다**(`.hero`·`.pill`·`.sec` 그룹화·접힌 줄 숫자 요약·차트 toggle 리사이즈). 같은 실수를 반복하지 마라.

import re

def _selectors(css: str) -> set:
    # 주석을 먼저 지운다. 안 그러면 `[^{}]*`가 개행을 넘어 앞 주석까지 삼켜
    # `/*그룹섹션…*/details.sec` 같은 오염된 키가 되고, 정작 주석이 붙어 있는
    # details.sec·.sec-body>.panel 두 규칙을 못 잡는다(2026-08-12 리뷰에서 실행으로 확인).
    css = re.sub(r"/\*.*?\*/", " ", css, flags=re.S)
    return {re.sub(r"\s+", "", m.group(1))
            for m in re.finditer(r"([^{}\n][^{}]*)\{[^{}]*\}", css)}


def test_live_page_does_not_redefine_shared_rules():
    """live_page.py는 __BASE_CSS__를 이미 싣는다 — 같은 셀렉터를 또 정의하면
    두 복사본이 갈라져도 아무도 모른다(2026-08-12: 10규칙이 바이트 동일 복제였다)."""
    from pathlib import Path
    src = Path("backend/report/live_page.py").read_text(encoding="utf-8")
    local = src.split("__BASE_CSS__", 1)[1].split("</style>", 1)[0]
    shared = _selectors(BASE_CSS)
    dupes = sorted(s for s in _selectors(local) if s in shared)
    assert dupes == [], "theme.py와 중복된 셀렉터: %s" % dupes
```

import subprocess

import pytest

from backend.report.theme import AGO_JS

needs_node = pytest.mark.skipif(shutil.which("node") is None,
                                reason="node 미설치 — JS 실행 테스트 생략")

CASES = [
    (0, "방금"),
    (-30 * 1000, "30초 전"),
    (-90 * 1000, "1분 전"),
    (-59 * 60 * 1000, "59분 전"),
    (-3 * 60 * 60 * 1000, "13:00"),      # NOW가 16:00 KST 고정이라 3시간 전 = 13:00
    (+2 * 60 * 60 * 1000, "2시간 뒤"),
    (+26 * 60 * 60 * 1000, "내일"),
    (+3 * 24 * 60 * 60 * 1000, "3일 뒤"),
    # 경계 — 유일한 분기 로직이므로 정확값을 덮는다(2026-08-12 리뷰 지적)

    (-60000, "1분 전"),                  # 60초는 '초 전'이 아니다
    (-3600000, "15:00"),                 # 60분은 '분 전'이 아니라 시각 표기
    (+86400000, "내일"),                 # 정확히 24시간 뒤 → 2026-08-13 16:00
    (+36 * 3600 * 1000, "2일 뒤"),       # 착지 2026-08-14 04:00 → 달력 2일
]


@needs_node
@pytest.mark.parametrize("delta,expected", CASES)
def test_ago_formats(tmp_path, delta, expected):
    # 2026-08-12 16:00 KST(= 07:00 UTC). 고정 NOW로 테스트가 시계에 안 흔들리게 한다.
    # 실측 확인: TZ=Asia/Seoul 에서 이 epoch는 16:00 정각이다(2026-08-12).
    now = 1786518000000
    js = tmp_path / "ago.js"
    js.write_text(AGO_JS + "\nconsole.log(ago(%d, %d));" % (now + delta, now),
                  encoding="utf-8")
    r = subprocess.run(["node", str(js)], capture_output=True, text=True, timeout=15)
    assert r.returncode == 0, r.stderr
    assert r.stdout.strip() == expected
```

function ago(t, now){
  var n = (now == null ? Date.now() : now), d = n - t;
  if (d >= 0) {
    if (d < 5000) return '방금';
    if (d < 60000) return Math.floor(d / 1000) + '초 전';
    if (d < 3600000) return Math.floor(d / 60000) + '분 전';
    var dt = new Date(t);
    return ('0' + dt.getHours()).slice(-2) + ':' + ('0' + dt.getMinutes()).slice(-2);
  }
  var f = -d;
  if (f < 86400000) return Math.max(1, Math.round(f / 3600000)) + '시간 뒤';
  // 달력 날짜로 센다. 경과 24시간으로 나누면 지금이 몇 시냐에 따라
  // 내일이 '2일 뒤'가 되고 모레가 '내일'이 된다(2026-08-12 리뷰에서 node 실행으로 확인:

  // 착지가 모레 05:00인데 '내일'로 나왔다).
  var a = new Date(t), b = new Date(n);
  var days = Math.round((new Date(a.getFullYear(), a.getMonth(), a.getDate())
                       - new Date(b.getFullYear(), b.getMonth(), b.getDate())) / 86400000);

}
