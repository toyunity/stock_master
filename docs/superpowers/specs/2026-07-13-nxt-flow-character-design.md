# 시간외(NXT) 자금 성격 추정 패널 — 설계

날짜: 2026-07-13 · 상태: 마스터 스펙 제공(원문 유지), 구현 세부만 보강

## 목적

정규장 마감(15:30) 후 NXT 시간외 가격 변동의 성격을 추정한다. 투자자별 주체
데이터는 KRX·정규장 기준 T+1이므로 3개 대용 지표로 우회한다. **모든 주체 추정에
"추정치(정확한 주체 식별 불가)" 라벨, 확정치는 T+1 09:30 이후 제공 표기.**

## 사전 조사 (구현 전 실검증 — probe-semi-nxt-sources 워크플로)

1. 시장구분(J/NX/UN) 파라미터별 TR 동작 (현재가·분봉)
2. 거래원(회원사) TR — `FHKST01010600` 후보 실검증
3. NXT 전용 실시간 TR 목록 확인 (H0NX*)
- 확인된 TR만 사용, 미확인 기능은 화면에 "미지원" 명시.

## 패널 1 — 거래소별 거래량 분리 (`backend/flow/exvol.py`)

- KIS 현재가를 div J / NX 로 각각 조회(60초 TTL) → KRX/NXT 누적 거래량 분리,
  NXT 비중% = NX / (J+NX).
- 세션 집계(장전 08:00-08:50 / 정규 / 장후 15:30-20:00): 엔진이 세션 경계
  통과 시점의 누적치를 스냅샷해 차분으로 산출. 서버가 경계 시점에 꺼져 있었으면
  해당 세션 '미집계' 표시(추정 금지). NX 분봉이 세션별 반환을 지원하면(프로브
  결과에 따라) 재기동 백필로 보강.
- 왜곡 경고: 시간외 가격 변동률(정규장 종가 대비) |Δp| ≥ 1% 인데 장후 NXT
  거래량이 당일 총거래량의 1% 미만이면 "유동성 부족 — 가격 왜곡 가능성" 경고.

## 패널 2 — 거래원(회원사) 창구 분석 (`backend/flow/member.py`)

- 프로브 확정 TR로 매수/매도 상위 회원사 조회(60초 TTL).
- 외국계 창구 상수: 모건스탠리, JP모건, UBS, 메릴린치, CS, 골드만삭스, 노무라,
  다이와, 맥쿼리, CLSA, 씨티, HSBC, BNP, 도이치, 소시에테제네랄 (+응답에 외국계
  플래그 필드가 있으면 그것을 우선).
- 표시: 매도/매수 상위 5 창구 표 + [외국계 합계] vs [국내 합계].
  "외국인이 국내 창구를 쓸 수 있음 — 추정" 라벨 필수.
- TR이 NXT 체결을 포함하지 않으면(KRX 전용) "정규장(KRX) 기준" 명시.

## 패널 3 — 체결 규모 분포 (FlowState 확장, 외부 의존 없음)

- 기존 웹소켓 체결(H0UNCNT0)에서 체결량 구간 집계:
  1-10 / 11-50 / 51-100 / 100주 초과 × 매수/매도 × 세션(장전/정규/장후).
  건수와 거래대금을 서버 카운터로 누적(자정 리셋 포함), 스냅샷에 포함.
- 화면: 세션 토글(기본=현재 세션) + 방향별 CSS 막대(거래대금 비중), 건수 병기.
- 판정(해당 세션 기준):
  - 100주 초과 매도 거래대금 비중 ≥ 40% → "기관성 매도 우세(추정)"
  - 100주 초과 매수 거래대금 비중 ≥ 40% → "기관성 매수 우세(추정)"
  - 1-10주 체결 건수 비중 ≥ 70% → "개인 물량 중심(추정)"
  - 그 외 → "혼재"
  - 시간외 세션은 표본이 얇을수록 판별력이 높다는 안내 문구.

## 공통 주의

- 크롤링/조회 실패 시 패널 "데이터 없음" + 대시보드 생존 (기존 패턴).
- 배치: /live 페이지, 실시간 체결 패널 위쪽에 3패널 연속 배치.
