# 반도체 동향 섹션 (메모리 중심) — 설계

날짜: 2026-07-13 · 상태: 승인됨 (마스터 구두 승인)

## 목적

"간밤 미국 반도체(특히 메모리)가 어땠고, 오늘 국내가 어떻게 반응하나"를
메인 대시보드(`/`) 최상단 한 섹션에서 답한다.

## 종목셋 (설정 `SM_SEMI_US` / `SM_SEMI_KR`로 재정의 가능)

- 미국: **SOX지수** + NVDA(수요 동인), **MU·WDC·SNDK**(메모리 본체),
  **AMAT·LRCX·KLAC**(메모리 장비 3대장), **SKHYV**(하이닉스 DR — 원주 괴리율 병기)
- 국내: 삼성전자(005930), SK하이닉스(000660)

## 아키텍처

- `backend/flow/semi.py`: `get_overview()` → 60초 모듈 TTL 캐시.
  - 미국 개별주: KIS `HHDFS00000300`(현재가, rate/sign 포함) EXCD=NAS,
    폴백 네이버 월드스톡 polling API (검증됨).
  - SOX 지수: KIS 해외지수 TR — **사전 프로브로 코드 확정**, 실패 시 네이버
    세계지수 폴백, 그것도 실패면 카드 '–'.
  - 국내: 기존 `KisClient.price()` (키 없으면 유니버스 캐시 종가).
  - SKHYV 괴리율: 기존 `adr` 모듈 계산 재사용.
  - rt_cd≠0은 예외 위임(빈 캐시 오염 금지 — 2026-07-13 리뷰 확정 규칙).
- API: `GET /api/semi` → JSON. 실패 종목은 필드 null, 섹션은 생존.
- 화면: `build_dashboard()` 상단에 섹션 삽입 + 인라인 JS가 `/api/semi` 60초 폴링.
  - 흐름 한 줄 요약: "간밤 SOX ±x% · MU ±y% → 오늘 하이닉스 ±z%".
  - 1행 미국 카드(미국 장마감 시 '전일 종가 기준' 라벨 — ET 시계 판정,
    /live ADR 패널과 동일 규칙), 2행 국내 카드(KST 기준시각 라벨).
  - 등락 색: 상승 적색/하락 청색(국내 관례) — 미국 카드도 동일 관례로 통일.

## 오류 처리 / 테스트

- 종목 단위 실패 격리(카드 '–'), 소스 전체 실패 시 섹션에 '데이터 없음'.
- 테스트: 파서 픽스처(미국 시세·지수·네이버 폴백), 대시보드 렌더에 섹션 포함,
  /api/semi 스모크(가짜 클라이언트), node JS 렌더 스모크는 기존 하니스 패턴.
