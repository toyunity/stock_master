# 토스증권 차트 이식 — 설계

작성 2026-07-15. 대상: `/live` 가격 차트(`backend/report/live_page.py`, Lightweight Charts v4).
레퍼런스: 사용자 제공 토스증권 SK하이닉스 일봉 스크린샷(IMG_3529).

## 목표
토스증권 차트의 **구성·스타일·주석**을 우리 PWA `/live`에 충실히 재현한다.
픽셀 단위 동일이 아니라, 아이폰 폭 CDP 스크린샷으로 레퍼런스와 대조하며 반복 수렴한다.

## 확정된 결정 (사용자)
- **토스 룩이 기본**, 어드바이저 오버레이(공매도·절대선/예약매도·수급 판정·크로스헤어 OHLC·카운트다운·실시간봉)는 **토글, 기본 off**.
- **최고/최저 라벨 = 전체(로드된) 기간 고정** — 줌/이동해도 안 바뀌고, 해당 봉이 화면 밖이어도 가장자리에 라벨 유지(추천값; 빌드 후 스크린샷으로 검증).
- 틱 차트는 데이터 없어 **제외**.

## 설계 (Phase 1 = 핵심 룩)
1. **헤더** — 뒤로 / 종목명 / 현재가(대) / 등락 `▲금액 · %`(적·청) / 우측 **일·분 탭**. `OFF`=이평 전체 토글.
2. **이평선 5·10·20·60·120** — `candles.py _attach_ma`에 ma5·ma10 추가. 색 토스 관례(5 회색·10 분홍·20 주황·60 녹·120 청). 상단 **범례 칩 탭 토글**. 데이터 부족 타임프레임은 기존 비활성 로직 재사용.
3. **최고/최저 자동 주석** — 로드된 봉의 최고·최저를 `pseries.setMarkers`로: `가격(MM.DD) ±%`(현재가 대비). **반드시 기존 `toTs()`(KST-epoch 변환, live_page.py:416)로 time 생성** — 안 그러면 날짜가 어긋나고 하니스는 통과시켜 CDP로만 잡힘.
4. **현재가 축 태그** — nowLine을 상승 적/하락 청 컬러 축 라벨(가격)로. 등락%는 헤더에 크게.
5. **거래량** — 막대를 봉 방향색(적/청) + `거래량` 라벨 + 현재값 태그.
6. **어드바이저 오버레이 토글 골격** — 위 기능들을 "지표/고급"에 모아 토글(기본 off). 실시간봉+현재가 라인은 은은하게 유지 검토.

## Phase 2 (후속)
일/분 드롭다운 · ⚙(이평 선택)/🔧(그리기=절대선) 메뉴 · 배당락 이벤트 마커(데이터 조사) · 진짜 멀티페인/축 % 태그(라이브러리 업글 필요).

## 제약·보존
- SSE `render()` 계약과 element ID **불변**. 엔진(FlowEngine/KIS) 미변경.
- 모든 신규 차트 API는 **node 하니스 가드**(`if(pseries.setMarkers)` 등) — 하니스에 없는 API로 죽지 않게.
- 기존 301 테스트 유지 + 신규 로직(ma5/ma10, 최고/최저 계산) 단위 테스트 추가.

## 검증
- **CDP 스크린샷 대상**: 8001을 반드시 `SM_FLOW_MODE=demo SM_AUTH_ENABLED=false`로 재기동(라이브 모드로 띄우면 KIS 1키1세션을 다시 훔쳐 8000 실시간이 죽음 — [[server-restart-ops]]). 8000은 인증 게이트라 헤드리스 스크린샷 불가.
- 아이폰 폭(390) 라이트/다크 스크린샷을 레퍼런스와 대조하며 반복.

## Non-goals
픽셀 완전 동일 · 틱 차트 · 배당락(Phase 1) · HTS 세로/가로 회전.
