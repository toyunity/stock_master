# PWA UI 대대적 업그레이드 — 설계

작성일: 2026-07-14 · 대상: `/live`·`/`(대시보드)·`/scanner`·`/login`·`/2fa`

## 목표

아이폰(PWA)에서 깨지거나 제대로 표현되지 않는 UI를 전면 수리하고, 개인용
주식 어드바이저 앱에 걸맞은 **대담한 새 비주얼 아이덴티티**로 업그레이드한다.
데이터·실시간(SSE)·차트 **로직은 그대로 두고**, 껍데기(CSS·마크업 구조·차트 외관
옵션)만 바꾼다.

## 근거(실제 아이폰 폭 390px 캡처로 확인한 현상)

1. **가로 오버플로** — 대시보드가 415px CSS 폭으로 렌더(390 초과 25px). 페이지가
   좌우로 밀림.
2. **다크모드 없음** — 아이폰 다크모드 사용자에게 백색 플래시/눈부심.
3. **세이프에어리어 미대응** — `viewport-fit=cover`·`env(safe-area-inset-*)` 없음 →
   노치/홈 인디케이터 밑으로 콘텐츠가 들어감.
4. **헤더 배지 혼잡** — 종목명 + 배지 3개(DEMO·수신중·애프터마켓 NXT) 줄바꿈 위험.
5. **탭 타겟 < 44px** — 타임프레임 `.tf` 버튼 높이 ~32–36px(애플 최소 44px 미달).
6. **긴 버튼 혼입** — "🔔 감시선 알림 허용"이 [1분][5분][15분][일봉] 세그먼트에 끼어
   혼잡.
7. **평면·단조·고밀도** — 회색 일변도, 1px 얇은 테두리, 11–13px 폰트, 위계 부재 →
   초보자에게 과부하.
8. **넓은 테이블 압박** — 거래원(4열)·(접힌) 일별 확정수급(6열)·기관 세부가 좁은 폭에서
   압박.
9. **신선도 라벨이 제목 줄로 말려 들어감**.
10. **시그널이 밋밋한 텍스트** — 컬러 칩(pill)으로 승격 필요.

## 반드시 보존(건드리지 않음)

- `render()`·SSE 재접속/워치독·차트 KST/UTC 처리·감시선·Y축 도메인 고정 등 **모든 JS
  로직과 element ID**(테스트 `test_live_page_js.py`가 실제 `render(S)` 실행으로 검증).
- 한국식 **상승=적색(#c62828)/하락=청색(#1565c0)** 관례.
- **신선도·추정 라벨**(정직성 — 앱 핵심 가치).
- **자기완결**(빌드 없음·오프라인·외부 폰트/CDN 0·CSP 안전).
- **Python 3.9 호환**(마스터 실서버는 시스템 3.9로 기동 — match문·`X|Y` 힌트 금지).

## 설계

### A. 공유 디자인 시스템 모듈 — `backend/report/theme.py`

4개 화면에 흩어진 CSS 중복을 단일 출처로 통합. export:

- `PWA_HEAD` — `viewport-fit=cover` 추가, 라이트/다크 `theme-color` 대응.
- `BASE_CSS` — 디자인 토큰을 CSS 커스텀 프로퍼티로:
  - `:root`(라이트) + `@media (prefers-color-scheme: dark)`(다크) 팔레트.
  - 타이포 스케일·간격 스케일·라운드·그림자 토큰.
  - 컴포넌트 클래스: `.panel`/`.card`(승격 카드), `.stat`(스탯 타일), `.pill`(시그널
    칩), `.seg`(세그먼트 컨트롤), `.tbl-wrap`(가로 스크롤 컨테이너), `.badge`,
    세이프에어리어 패딩 유틸.
- `NAV_LOADER`·`DISCLAIMER`를 이곳으로 이전(현재 dashboard.py 소재) → 전 페이지 공유.

각 페이지는 자체 `<style>`에서 화면 고유 스타일만 남기고 공통은 `BASE_CSS`를 주입.

### B. 비주얼 언어(대담한 새 아이덴티티)

- **카드 승격**: 은은한 그림자, 큰 라운드(~16px), 넉넉한 패딩. 섹션 헤더 = 아이콘 +
  제목 + (그 아래) 신선도 캡션(제목 줄에 말리지 않게).
- **시그널 → 컬러 칩(pill)**: good(녹)·warn(호박)·info(청)·flat(회). 매매 타이밍·대차·
  신용·체결규모·거래원 판정에 일관 적용.
- **스탯 타일**: `grid3` → `.stat`(라벨/값 위계, tabular-nums, 반응형).
- **세그먼트 컨트롤**: 타임프레임을 `.seg`로(44px 타겟). 🔔은 컴팩트 아이콘 버튼으로 분리.
- **헤더**: 종목명 강조 + 상태 배지는 컴팩트 상태 칩으로 우아하게 래핑.
- **큰 가격 타이포**: 현행 유지·정제.

### C. 반응형·아이폰 정합

- `viewport-fit=cover` + body/헤더 `padding: env(safe-area-inset-*)`.
- 넓은 테이블은 `.tbl-wrap{overflow-x:auto;-webkit-overflow-scrolling:touch}`로 감싸
  **페이지 레벨 가로 오버플로 0**.
- 대시보드 415px 오버플로 원인 제거(그리드/차트 `max-width:100%`·`min-width:0` 보정 +
  body `overflow-x:hidden` 안전판).
- 필요 구간 `clamp()` 유동 타이포. 모든 탭 타겟 ≥44px.

### D. 다크모드(자동)

- `prefers-color-scheme: dark` 토큰 팔레트.
- 차트는 테마 감지값을 LightweightCharts `layout.background`/`textColor`/`grid`
  **외관 옵션에만** 반영(데이터 로직 불변). `<meta name="theme-color">`도 스킴별.

### E. 엔진 불변

CSS + 마크업 구조 + 차트 외관 옵션만. 모든 element ID·`render()`·SSE·워치독·감시선·
Y축 고정 보존. auth.py의 로그인/2FA/2FA설정 HTML도 같은 시스템으로 재스타일.

## 검증

- 리디자인 전/후 **아이폰 폭(390px) CDP 풀페이지 스크린샷** 4~5개 화면 비교.
- `pytest`(특히 `test_live_page_js.py` — 실제 `render()` 실행) 그린.
- 페이지 폭 == 390px(가로 오버플로 없음) 확인.

## 롤아웃 순서

1. `theme.py`(디자인 시스템) 작성.
2. **파일럿: `/live`**(가장 복잡·핵심)에 적용 → 아이폰 폭 캡처로 검증.
3. 확인 후 `/`(대시보드) → `/scanner` → auth(로그인·2FA)로 확산.
4. 전 화면 before/after + pytest 그린으로 마무리.

## 비목표(YAGNI)

- 프레임워크·빌드 스텝 도입 금지. 외부 폰트/아이콘 CDN 금지.
- 데이터·판정 로직 변경 금지. 새 패널 추가 아님(순수 UI/디자인 + 감시선 편집 UI).
- 서비스워커/오프라인 캐시 고도화는 범위 밖(별도 과제).
