# S5 실시간 수급 모니터 (영웅문식 종목별 수급) — 설계

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-07-10 (장중 데이터 소스 실측 검증 완료) |
| 목표 | 특정 종목(기본 SK하이닉스 000660)의 실시간 수급 — 체결, 프로그램매매, 외국인/기관 잠정, 일별 확정 — 을 영웅문처럼 한 화면에서 관측 |
| 범위 | 관측 전용(주문 없음) · 개인 1인용 · 기존 FastAPI 웹앱/PWA에 페이지 추가 |

## 1. 데이터 현실 (2026-07-10 실측 — 설계의 근거)

| 소스 | 결과 |
|---|---|
| KRX 정보데이터시스템 | ❌ 로그인 의무화('25.12.27) 실적용 — 모든 getJsonData 호출이 HTTP 400 `LOGOUT` (라이브 확인) |
| pykrx 투자자 함수 | ❌ 위 벽에 막혀 **조용히 빈 DataFrame** 반환 |
| FDR 투자자 데이터 | ❌ 유일한 리더가 finance.naver.com 스크래핑 — 프로젝트 금지(§3) |
| KIS 오픈API | ✅ 유일한 합규 경로. 공식 리포지토리에서 필드 단위 스펙 확보(아래 §3). 무료·맥 호환·키는 계좌 개설 당일 발급 가능 |
| 키움 REST API | ✅ 대안 확인(2025-06 출시, 맥 호환, ka10063 장중투자자별매매) — 역시 계좌 필요. 2순위 폴백으로 기록만 |

**충실도 상한(중요)**: 장중 외국인/기관 수치는 영웅문에서도 **창구 기반 추정치**로 하루 4회(외국인 09:30/11:20/13:20/14:30, 기관 10:00/11:20/13:20/14:30 ±10분) 갱신되고 익일 아침 확정된다. 진짜 틱 실시간은 **프로그램매매**와 **체결가**뿐. 어떤 API도 이 이상은 불가능하며, KIS로 영웅문과 동일 수준을 얻는다.

## 2. 접근법 비교

| 접근 | 평가 |
|---|---|
| **A. KIS 본선 + 데모 모드 폴백 (채택)** | S5 잠금 결정 그대로. 키 없이도 데모 스트림으로 화면 전체가 오늘 동작·검증 가능. 키 입력 즉시 라이브 전환 |
| B. 키움 REST로 전환 | 장중투자자별매매 TR이 다소 풍부하나 역시 계좌 필요 + 신규 통합 비용. 이점이 전환 비용을 못 넘음 → 기각(폴백 후보로만 기록) |
| C. 네이버/다음 폴링 | 설계 §3 금지 사항 → 기각 |
| D. 키 나올 때까지 대기 | 사용 가능한 앱 우선 원칙 위배 → 기각 |

## 3. KIS 연동 스펙 (공식 koreainvestment/open-trading-api에서 검증)

- **인증**: `POST {domain}/oauth2/tokenP` → access_token(24h, 재발급 1회/분, 6h 내 재요청 시 동일 토큰 — **디스크 캐시 필수**). `POST /oauth2/Approval`(body 필드명은 `secretkey`) → 웹소켓 approval_key. 실전 도메인 `openapi.koreainvestment.com:9443`, 웹소켓 `ws://ops.koreainvestment.com:21000`.
- **웹소켓**(구독 41건 한도, PINGPONG 에코 필수, 데이터 프레임 `0|TRID|n|필드^필드...`):
  - `H0STCNT0` 실시간 체결가(46필드: 현재가·등락·체결량·누적거래량·체결강도 등) — 실전+모의.
  - `H0STPGM0` 종목별 프로그램매매(11필드: 매도/매수 체결량·대금, **순매수 체결량/대금**, 호가잔량) — **실전 전용**.
- **REST**(초당 20건 실전 / 2건 모의):
  - `FHKST01010900` 주식현재가 투자자 — **일별 확정** 개인/외국인/기관 순매수(약 30일치, 당일분은 장 종료 후). 모의 지원.
  - `HHPTJ04160200` 종목별 외인기관 **추정가집계** — 장중 잠정(하루 4회), `bsop_hour_gb` 시각 구분 포함. 실전 전용. (⚠️ TR이 `HH`로 시작 — `FH` 아님)
  - `FHPPG04650101` 종목별 프로그램매매추이(당일 시계열) — 장중 재접속 시 차트 백필용. 실전 전용.
- **모의투자 키 한계**: 체결가 웹소켓 + 일별 투자자만 가능. 수급 전용 TR(프로그램·추정)은 실전 키 필요 → **실전 키(관측 전용, 주문 미사용)를 기본 가정**.

## 4. 아키텍처

```
backend/flow/                    # 새 모듈 — 종목별 실시간 수급
├── models.py     # FlowState: 스냅샷 dict 빌더(체결 테이프·프로그램 누적·투자자 잠정/일별)
├── kis.py        # KIS 클라이언트: 토큰/approval 캐시, REST 3종, WS 프레임 파서(순수 함수)
├── demo.py       # DemoSource: 시드 랜덤워크 시뮬레이션(키 없이 화면 검증)
└── engine.py     # FlowEngine: 모드 선택(키 유무), asyncio 태스크, 1초 스냅샷 브로드캐스트
backend/api/app.py               # + GET /live/{code}(HTML), GET /api/live/{code}/stream(SSE)
backend/report/live_page.py      # 자기완결 HTML(기존 dashboard.py 패턴) + EventSource JS
```

- **전달 방식: SSE**(EventSource) — 아이폰 PWA·http-LAN에서 자동 재접속 포함 가장 단순. 서버가 **1초마다 전체 스냅샷 JSON**을 push(상태가 수 KB라 diff 프로토콜 불필요 — 클라 상태 병합 버그 원천 차단).
- **FlowEngine**: 코드별 싱글턴. KIS 모드 = WS 수신 태스크(체결·프로그램 즉시 반영) + REST 폴러(추정가집계 5분 간격/장중, 일별 투자자 시작 시 1회+장후 1회, 프로그램추이 백필 1회). 데모 모드 = 0.5~2초 간격 가짜 체결/프로그램 + 4회 잠정 스냅샷 시뮬레이션.
- **모드 선택**: `.env`에 `SM_KIS_APP_KEY`/`SM_KIS_APP_SECRET` 있으면 LIVE, 없으면 DEMO. `SM_FLOW_MODE=demo`로 강제 데모 가능. 화면에 모드 배지 상시 표시(데모를 실데이터로 오인 금지).
- **장시간 외**: LIVE 모드여도 장전/장후엔 WS 이벤트가 없음 — 일별 확정 패널과 마지막 스냅샷 표시(라벨로 명시).

## 5. 화면 (/live/000660 — 모바일 우선, 영웅문 종목별 수급 축소판)

1. **헤더**: 종목명·현재가·등락(▲빨강/▼파랑)·누적거래량·체결강도 + 모드 배지(LIVE/DEMO) + 연결 상태.
2. **투자자별 잠정(장중 추정)**: 외국인/기관/합산 순매수 — 갱신 시각(`11:20 기준`) 라벨 필수, "잠정·익일 확정" 고지.
3. **프로그램매매**: 당일 누적 순매수(주·금액) + 인트라데이 순매수 추이 라인차트(Lightweight Charts, 실시간 append).
4. **일별 확정 수급**: 최근 10일 개인/외국인/기관 순매수 표(전일까지 확정치).
5. **실시간 체결 테이프**: 최근 30건(시각·가격·체결량·매수/매도 색).
6. 투자 유의 고지 + 데이터 출처(KIS·KRX) — 기존 §16 문구 재사용.

모든 수치에 **신선도 라벨**(실시간 / 잠정 hh:mm 기준 / 전일 확정)을 붙인다 — 초보자가 추정치를 확정치로 오해하지 않도록(교육 레이어 원칙).

## 6. 에러 처리

- WS 끊김: 지수 백오프 재접속(±지터), 재접속 시 REST 백필. PINGPONG 미응답 방지.
- 토큰 만료/EGW00201(레이트): 캐시 토큰 재사용 우선, 실패 시 페이지에 상태 표시(죽지 않음).
- SSE 클라 끊김: 큐 정리(구독자 0이면 폴러 유휴). EventSource가 자동 재접속.
- 키 무효(EGW00103): 데모 모드로 강등 + 화면에 원인 표시.

## 7. 테스트 전략 (TDD)

- **파서 순수 함수**(픽스처 기반 — 검증된 필드 순서로 작성): H0STCNT0 46필드, H0STPGM0 11필드, 멀티레코드 프레임, PINGPONG, 구독 ACK.
- **REST 파싱**: 문서 필드명 기반 목 응답 → 모델 변환.
- **엔진(데모)**: 스냅샷 스키마·테이프 상한·프로그램 누적 단조성.
- **API**: /live/{code} HTML 라우트, SSE 스트림 첫 이벤트 수신(TestClient).
- **라이브 검증**: 데모 모드는 오늘 즉시. KIS 라이브는 키 입력 후 장중 검증(체크리스트를 상태 문서에 기록).

## 8. 키 발급 안내 (사용자 액션 — 유일한 선행 조건)

한국투자증권 비대면 계좌 개설(모바일, 수분·당일) → KIS Developers(apiportal.koreainvestment.com) API 신청 → App Key/Secret 즉시 발급 → `.env`에 `SM_KIS_APP_KEY=...`, `SM_KIS_APP_SECRET=...` 추가 → 서버 재시작. 주의: 최근 20영업일 내 타 금융기관 계좌 개설 이력이 있으면 비대면 개설이 막힐 수 있음.
