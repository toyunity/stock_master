# kospinow.com 해부 — 무엇을 어떻게 가져오고, 우리가 뭘 가져올까

조사일 2026-08-12. 방법은 **번들 정적분석 + 정적 JSON 신선도 + 원천 API 직접 호출**이다.
브라우저 확장이 안 붙어 실시간 네트워크 관찰은 못 했다 — 아래 호출 경로는 번들에서
읽은 것이고, 원천(Binance)은 내가 직접 때려서 확인했다.

---

## 1. 데이터를 어떻게 가져오는가

### 체인

```
아이폰/PC 브라우저
   │
   ├─ GitHub Pages (server: GitHub.com, Fastly, 서울 엣지)  ← HTML·JS·CSS 전부 정적
   │     └ /data/baseline.json   국내 시가·종가 + 앵커 시각      (GitHub Actions가 갱신)
   │       /data/economic.json   미국 지표 발표일정 (출처 FRED)  (〃)
   │       /data/latest.json     스냅샷 폴백                      (〃, **10일째 정지**)
   │       /data/history.json    미니 히스토리                    (〃, **1건뿐**)
   │
   ├─ fapi.binance.com  /  wss://fstream.binance.com   ← 브라우저가 **직접** 호출
   │     실시간 가격의 100%가 여기서 온다. 키 없음, CORS 열림, 24/7
   │
   └─ stock-predict-board.kospinow.workers.dev  (Cloudflare Worker)
         /api/posts · 댓글 · 채팅 · 로그인 — 게시판/채팅 전용. 시세와 무관
```

서버가 없다. 시세 백엔드가 **0원**이다. 수익화는 AdSense(`ca-pub-7766090864059500`) + GA4.

### 핵심: 바이낸스에 삼성전자·SK하이닉스 무기한선물이 상장돼 있다

`GET /fapi/v1/exchangeInfo` 실측 (2026-08-12):

| 항목 | 값 |
|---|---|
| `symbol` | `SAMSUNGUSDT` / `SKHYNIXUSDT` / **`HYUNDAIUSDT`** |
| `contractType` | `TRADIFI_PERPETUAL` |
| `underlyingType` | `KR_EQUITY` (3종 — 현대차는 아래 ①에서 **기각**) |
| `onboardDate` | 1780369800000 = 2026-06-03 |
| 24h 거래대금 | 삼성 **2.49억 USDT** (호가 스프레드 0.001%) |

즉 "야간선물"은 KRX 야간선물이 아니라 **바이낸스의 24시간 주식 무기한선물**이다.
kospinow는 아직 현대차(`HYUNDAIUSDT`)를 안 쓰고 있다.

### 추정가 계산식 (번들에서 그대로 읽음)

```js
// 함수 vl()
s = currentBinancePrice / baselineBinancePrice - 1
i = krxClose * (1 + s)
estimatedPrice = 호가단위반올림(i)      // 함수 Ng()
```

`baseline.json`이 나르는 건 **국내 가격과 앵커 시각뿐**이다. 그 시각의 선물가는
브라우저가 직접 되찾아온다:

```
GET /fapi/v1/markPriceKlines?symbol=SAMSUNGUSDT&interval=1m&startTime=<앵커>&limit=1
```

앵커는 두 개(`open` 09:00 KST / `close` 15:30 KST)이고 기본은 `close`다.
**이건 옳은 선택이다** — 실측으로 확인했다:

| 앵커 | 삼성 내재환율 | 하이닉스 내재환율 | 두 종목 불일치 |
|---|---|---|---|
| 종가(15:30) | 1,412.2 | 1,412.3 | **0.01%** |
| 시가(09:00) | 1,421.5 | 1,416.7 | 0.34% |

종가 앵커에서 두 종목이 소수점까지 같은 환율을 가리킨다 → 선물가는
**원화 주가 ÷ 원달러환율**의 달러 표시다. 시가 앵커가 어긋나는 건 09:00 단일가
동시호가와 선물 1분봉의 시각 불일치 탓이다. FDR 원달러 08-12 시가 1,412.31과도 일치한다.

### 참조가 선택과 방어 로직

- `referencePriceMode: "mark"` — markPrice 우선, 없으면 (bid+ask)/2, 그다음 lastPrice
- 이상치 컷: 직전가 대비 **0.5배~2배** 벗어나면 그 틱을 버린다
- 30% 초과 변동은 콘솔 경고만
- 폴백 사슬: `binance-websocket` → `binance-rest` → `github-snapshot` → `github-actions`

### confidenceScore (100점 감점식)

```
시세 없음                       → 0
데이터 60초 초과 지연           → -10   (300초 초과면 추가 -30)
호가 스프레드 0.5% 초과         → -10   (호가 자체가 없으면 -10)
24h 거래량 1000 미만            → -15
markPrice 없음                  → -10
앵커가 오늘 것이 아님/없음      → -25
주말                            → -10
폴백 데이터 사용 중             → -20
```

상태값은 `healthy / stale / error / loading / no-baseline`, 화면 문구는
`국내장 거래 중 / 국내장 마감 / 야간 참고가격 / 주말 참고가격 / 국내 휴장 /
데이터 지연 / 기준가격 갱신 필요`.

### 여기서 배울 것 하나 — 폴백이 조용히 썩었다

`latest.json`의 `generatedAt`은 **2026-08-02**, `history.json`은 **1건**.
그런데 `baseline.json`은 오늘(08-12) 갱신된다. 즉 GitHub Actions의 스냅샷 잡만
10일째 안 돌거나 은퇴했는데, 화면은 멀쩡하다 — 브라우저가 바이낸스를 직접 보니까.
**아무도 안 쓰는 폴백은 살아 있는 척한다.** 우리가 `wsbus.py`에서 REST 폴백 때문에
"화면은 멀쩡한데 실시간은 죽어 있던" 그 함정과 같은 종류다.

## 2. 우리가 반영할 것 — 검증 결과 순

### ① 야간·주말 종목별 참고가 (삼성·SK하이닉스만) — 검증 통과, 최우선

간밤 선물 변동으로 다음날 국내 시가를 맞히는지 **48거래일** 실측했다
(FDR 일봉 시가 대 예측, 앵커=전일 15:30 선물, 예측시각=당일 09:00 선물).

| 종목 | 전일종가로 찍기 | 선물 예측 | 갭 방향 적중 | 내재환율 | 판정 |
|---|---|---|---|---|---|
| 삼성전자 | 중앙값 3.18% (평균 3.80%) | **1.19%** (평균 1.59%) | 94% | 1,412 | 채택 |
| SK하이닉스 | 중앙값 3.46% (평균 4.42%) | **1.60%** (평균 2.03%) | 81% | 1,412 | 채택 |
| **현대차** | 중앙값 1.44% (평균 1.99%) | **1.69%** (평균 1.89%) | 79% | **1,509** | **기각** |

삼성 기준 예측오차 1% 이내가 40%, 3% 초과가 15%. 두 종목에서 **전제는 실증됐다.**
(조사창은 7/31 +24% 갭 같은 극단이 낀 고변동 구간이었다 — 그래서 평균과 중앙값을 같이 적었다.)

**현대차는 쓰면 안 된다.** 중앙값 기준으로 선물 예측이 전일종가로 찍는 것보다 **더 나쁘다**.
원인은 내재환율에서 보인다 — 삼성·하이닉스가 1,412(실제 원달러와 일치)인데 현대차만 1,509,
즉 **7% 베이시스가 낀 얇은 계약**이다. 게다가 현대차는 원래 야간 갭이 작아서(전일종가로
찍어도 1.44%) 계약 노이즈가 신호를 덮는다. kospinow가 상장된 3종 중 2종만 쓰는 건 우연이 아닐 수 있다.
**교훈: 종목을 늘릴 때마다 내재환율이 실제 환율과 붙는지부터 본다. 벌어지면 그 계약은 버린다.**

⚠️ `SAMSUNGUSDT` 상장일이 2026-06-03이라 **이 48일은 계약 수명 거의 전체다 — out-of-sample이 없다.**
우리 백테스트 게이트에 붙여둔 단서("배관이 동작함을 증명할 뿐")를 여기에도 그대로 적용한다.

우리에게 이건 신규다. 지수 선물 칩(코스피200 야간)은 있지만 **종목별 야간 참고가는 없다.**
그리고 이 경로는 **KIS를 한 번도 안 건드린다** → 1키 1세션 제약과 무관하다.

### ② 미국 종목 24/7 가격 — 우리 README가 적어둔 한계를 없앤다

바이낸스 TradFi 무기한선물 목록(2026-08-12 실측, 총 154종):

- **US 주식 133종** — 우리 반도체 그리드가 거의 통째로 있다:
  `NVDA MU WDC SNDK AMAT LRCX KLAC TSM ASML AVGO AMD QCOM ARM INTC MRVL TER
   ALAB CRDO COHR CIEN LITE AAOI DRAM` + **`SKHY`(SK하이닉스 나스닥 DR)** + **`SMH`**(반도체 ETF)
   + `SOXL/SOXS`
- **지수 프록시** — `SPY QQQ IWM TQQQ SQQQ UVXY(VIX성)` + **`EWY`(한국 ETF)**, **`KORU`(한국 3배)**
- **원자재 8종** — `XAUUSDT`(금) `CLUSDT`(WTI) `BZUSDT`(브렌트) `XAGUSDT` `COPPERUSDT` `NATGASUSDT`
- **홍콩 11종**, PREMARKET 2종(`OPENAIUSDT` `ANTHROPICUSDT`)

미국 종목도 같은 하네스로 47거래일 검증:

| 종목 | 전일종가 | 선물 예측 | 내재환산계수(주가/선물) |
|---|---|---|---|
| NVDA | 1.11% | 0.79% | **1.0005** |
| MU | 3.96% | **1.82%** | **1.0008** |

환산계수가 1.0이라는 게 중요하다 — 미국 주식 선물은 1:1 달러 청구권이고,
따라서 **한국 종목의 1,412 계수는 순수 환율**이라는 위 모델이 판별식으로 확인됐다.

NVDA의 개선폭이 작은 건 당연하다(미국은 프리마켓/애프터가 이미 있다). 우리에게 값어치는
"개장가 예측"이 아니라 **주말 포함 24/7로 미국 반도체가 움직이는 걸 본다**는 것이다.
README가 "미국 종목엔 실시간이 의도적으로 없다(KIS 1키 1세션)"고 적은 그 *이유*가 사라진다.

### ③ 원자재를 FDR에서 바이낸스로 — 문서화된 함정의 정면 대체

우리 원자재(WTI·금)는 FDR이 원천이고, **마지막 봉이 종가가 아니라 10~12분 지연 현재가인데
날짜 라벨만 어제**인 함정을 `worldidx.py`가 `basis_kind`로 우회하고 있다.
`CLUSDT`/`XAUUSDT`는 24/7 실시간에 시각이 정확하다. 다만 **바이낸스 선물가는 CME 원유선물과
같은 값이 아니다** — 채택하면 `basis_kind` 신선도 판정과의 정합을 먼저 맞춰야 한다.

### ④ 미국 지표 발표 캘린더 (FRED) — 싸고 초보자 가치가 큰 항목

`/data/economic.json`: CPI·PPI·고용보고서·소매판매·PCE·GDP를 발표 UTC 시각과 함께.
화면엔 한국시간 + **상대시간("2시간 뒤" / "내일" / "2일 뒤")** + 출처(BLS/Census/BEA),
그리고 "시장 예상치는 제공하지 않습니다"를 명시한다(예상치는 유료·라이선스 영역이라 뺀 것).

FRED `releases/dates` API는 무료 키 1개면 된다. 우리 홈 화면의 "간밤 SOX가 어땠나" 옆에
"오늘 밤 21:30 CPI"가 붙는 건 초보자에게 큰 값이다.

### ⑤ 신선도 규율 — 우리 것과 **수렴 설계**다, 두 번째 체계를 들이지 마라

`confidenceScore`/`status`는 우리 `basis_kind`·칩별 기준일과 같은 문제의식이다.
배울 건 점수 자체가 아니라 **감점 항목의 목록**(지연·스프레드·거래량·앵커 나이·주말·폴백)이다.
우리 판정에 없는 축은 거래량과 스프레드다. 점수 체계를 새로 만들지 말고 항목만 흡수한다.

### ⑥ 기각 — 우리에겐 무관

게시판·채팅·Turnstile·회원가입·AdSense·공유 카드·GitHub Pages 정적 아키텍처.
1인용 비공개 앱이다. 프레임워크 교체와 대규모 재작성은 CLAUDE.md가 금지한다.
(공유 카드의 canvas 렌더는 기술적으론 재밌지만 쓸 데가 없다.)

## 3. 채택 전 반드시 확인할 것

- **환율이 섞여 있다.** 추정가 = 국내종가 × (선물now/선물앵커)인데, 선물은 달러 표시라
  실제로는 `× (환율now/환율앵커)`가 빠져 있다. 원화가 1% 약해지면 주가가 안 변해도 -1%로 보인다.
  → **다만 보정은 못 한다.** FDR 원달러는 일봉이라 밤사이 `환율now`가 없다(마지막 인덱스가
  당일 00:00에 고정). 48일 백테스트는 이 오차를 안고도 중앙값 3.18%→1.19%를 냈으므로
  2차항이다. **기능이 아니라 한 줄 라벨로 처리한다** — "달러표시 선물 기준, 환율 변동분 포함".
- **호가단위 표를 그대로 베끼지 마라.** 그들의 표는
  `<1,000:1 / <5,000:5 / <10,000:10 / <50,000:50 / <100,000:100 / <500,000:500 / 이상 1,000`인데,
  삼성(24만)·하이닉스(150만)에선 정확해서 그들 화면에선 절대 안 틀린다. 우리 관심종목은
  1,000~200,000원대가 대부분이라 밴드 경계가 문제가 된다. **현행 KRX 규정으로 재확인 필요**
  (KRX 메인 페이지에선 표를 못 찾았다 — 규정포탈 확인 필요). 참고로 우리 리포엔
  호가단위 개념이 아예 없다(`watch.py:_round_price`는 원 단위 정수 반올림뿐).
- **휴장일을 모른다.** 그들의 `Bi()`는 토·일만 본다(그래서 `holiday-unknown` 상태가 따로 있다).
  **우리는 KIS 휴장일 TR이 있다 — 이 지점은 우리가 이미 낫다.**
- **주말은 호가가 얇다.** 8/8~8/9 1시간봉 거래량이 평일의 **1/100**(1,500 대 238,000)이고
  가격은 ±0.7%에서 굳는다. 주말 값은 "참고"보다 더 약하게 표기해야 한다.
  그들도 "주말에는 거래량과 유동성이 낮아 예상가격의 변동성이 커질 수 있습니다"를 띄운다.
- **컴플라이언스.** 바이낸스 선물가를 국내 주식 예상가로 표시하는 건 **개인용·비재배포**
  전제에서만 안전하다. `commercialization-verdict`(실시간 시세 재배포=하드블로커) 판정을
  이게 완화하지 않는다.
- **구현 제약.** Python 3.9 문법, 새 의존성 금지(기존 httpx로 충분), 화면 고치면 `make verify`.

### 배울 문구 규율

"해외 선물가격 연계상품 기반 **참고** 예상가이며 실제 국내 체결가격과 다를 수 있습니다.
투자 권유가 아닙니다." / "현재 한국거래소 정규장이 진행 중입니다. **실제 체결가 기준으로
거래하세요.**" — 장중엔 자기 숫자를 스스로 내려앉힌다. 우리의 감성태깅 금지 원칙과 같은 계열이다.

```
--border-subtle rgba(255,255,255,.07) / rgba(0,0,0,.07)   (+mid .05 / strong .13)
```

의미색은 CSS 변수에 **없고** JS 상수로만 있다:
`rise #ff4d5e` · `riseSoft rgba(255,77,94,.14)` · `fall #3f82ff` · `fallSoft …` ·
accent `#8b7cff` · positive `#31c48d` · warn `#f5b942`.

**크롬은 완전 무채색, 색은 정보에만.** 우리 "관제(Instrument)" 체계와 **같은 철학**이다.
다른 건 값의 톤뿐이다 — 우리 iris `#6a4ff0`/상승 `#e5342f`/하락 `#1f66e0`에 비해
그들은 한 단계씩 밝고 부드럽다(`#8b7cff` / `#ff4d5e` / `#3f82ff`).

타이포: 본문 **Pretendard**(jsDelivr CDN), 숫자 계기값은 **모노**. 우리도 모노 계기 숫자를 쓴다.
⚠️ Pretendard는 CDN이다 — 우리 "외부 네트워크 0" 규칙과 정면 충돌한다(한글 서브셋을
인라인하면 페이지마다 수백 KB가 붙는다). 채택하려면 이 대가를 먼저 결정해야 한다.

### 진짜 훔칠 것은 색이 아니라 **카드 문법**이다

종목 카드 하나가 이렇게 짜여 있다(위→아래):

```
┌ 상단 3px 방향색 바 ────────────────────  ← 카드 윗변이 등락 방향으로 물든다
│ SK하이닉스  [000660]              ∿∿ 스파크라인(방향색, 소프트 배경)
│
│ 1,527,000원          ← 히어로 숫자 ~72px, 단위까지 같은 크기
│ 예상가               ← 이게 무슨 숫자인지 한 단어
│
│ ( ▲ +23,000원 · +1.52% )   ← 소프트 틴트 필 pill
│ ──────────────────────────────
│ 최근 국내 종가 (08/12)      1,504,000원   ← 라벨 좌(secondary) / 값 우(모노)
│ 현재 해외 선물가             1,080.1992      헤어라인 divider로만 구분
│ 기준가 (08/12 종가)          1,064.0718   ← **계산 재료를 전부 공개한다**
│ 매수 / 매도 호가    1,080.14 / 1,080.15
│ 호가 스프레드                  0.0009%
│ ──────────────────────────────
│ ● 실시간                          1초 전   ← 상태 + 신선도를 카드마다
│ [차트 보기]                      [⤴ 공유]
└
```

배울 점 셋:

1. **히어로 하나 + 근거 레일.** 큰 숫자 하나를 놓고, 그 숫자를 만든 재료를 바로 밑에
   전부 편다. "체결강도 82.8"이 아니라 뜻을 같이 적는 우리 원칙의 레이아웃판이다.
2. **신선도가 칩이 아니라 카드 안에 산다.** `● 실시간 / 1초 전`, 지수 타일마다
   `장 마감` / `● 장중`. 우리가 "칩마다 기준일을 찍는다"고 정한 것과 같고, 그들은
   그걸 **모든 카드의 고정 슬롯**으로 만들었다.
3. **상대시간.** 지표 캘린더가 `2시간 뒤 / 내일 / 2일 뒤`로 말한다. 초보자에게
   `2026-08-12T12:30:00Z`보다 압도적으로 낫다.

### 그런데 — 이 디자인이 좋아 보이는 이유의 절반은 "보여줄 게 2개뿐"이라서다

kospinow는 전체 높이 2,379px에 카드 8장이다. 우리 `/live` 한 화면은 **30,000px 넘고**
패널이 20개가 넘는다. 그들의 여백·72px 히어로·카드당 5행 레일을 우리 밀도에 그대로 옮기면
세로가 3배가 된다. **그대로 이식은 불가능하고, 옮길 수 있는 건 문법(카드 구조·신선도 슬롯·
상대시간·근거 레일)이지 여백값이 아니다.**

우리 디자인 체계는 2026-07-20에 5차 "관제"로 전면 교체했고, 그 철학(무채색 크롬 + 색=정보 +
모노 계기 + 틱룰 divider)은 kospinow와 **이미 같다**. 그래서 6차 전면 교체는 얻는 것보다
잃는 것(회귀 위험·`/live` 패널 삭제 금지 제약)이 클 수 있다. 실제로 차이 나는 지점만 적으면:

| 항목 | kospinow | 우리 | 옮길 값어치 |
|---|---|---|---|
| 팔레트 톤 | 한 단계 밝고 부드러움 | 진하고 대비 강함 | 중 — `theme.py` 토큰값만 조정 |
| 히어로 숫자 | 72px, 카드마다 하나 | 없음(계기 나열) | **상** — 종목 상세 최상단 |
| 근거 레일 | 계산 재료 전부 공개 | 판정 문장으로 설명 | 중 — 병행 가능 |
| 신선도 | 카드 고정 슬롯 | 칩·`basis_kind` | 중 — 슬롯화가 더 낫다 |
| 상대시간 | `2시간 뒤` | 절대시각 위주 | **상** — 싸다 |
| 카드 상단 방향색 바 | 3px | 없음 | 중 |
| 서체 | Pretendard(CDN) | 시스템 | 하 — 자기완결 규칙과 충돌 |
| 여백·밀도 | 넉넉 | 조밀 | **이식 불가** — 밀도가 다름 |
