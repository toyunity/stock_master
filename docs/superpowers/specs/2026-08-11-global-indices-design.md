# 글로벌 지표 섹션 — 미국채·금·유가·해외지수 (2026-08-11)

## 왜

야순지지(yasun.gg)가 한 화면에 국내와 글로벌을 같이 놓는다. 우리 대시보드엔 코스피·선물·환율만
있어 "미국이 어젯밤 어땠나"를 다른 앱에서 봐야 한다. 그 왕복을 없앤다.

**야순 분석 결론(재확인)**: Next.js 프론트가 자기네 백엔드(`/api/prices`, socket.io)만 부르고
상단 원천은 번들에 안 드러난다. 기존 `docs/yasun-gg-teardown.md`(2026-07-30)가 이미
소스맵을 밝혀뒀다 — **나스닥·S&P·VIX·환율·원자재는 Yahoo Finance**, 국내 선물은 증권사 오픈API,
개별종목은 네이버. 즉 단일 벤더가 아니라 무료 소스 스티칭이다.
**그쪽 사설 API는 쓰지 않는다** — 남의 피드 재사용이고, 이 프로젝트가 이미 결론 낸
재배포 금지선([[commercialization-verdict]])에 걸린다. "무엇을 보여주는가"만 참고한다.

## 원천 — 실측으로 확정 (2026-08-11)

| 지표 | 원천 | 실측값 | 단위 | 기준 |
|---|---|---|---|---|
| 미국채 2Y/10Y/30Y | 미 재무부 공식 XML | 4.25 / 4.72 / 5.25 | **%** | 08-10 (직전 영업일) |
| WTI 유가 | FDR `CL=F` | 82.13 | **$/배럴** | 08-10* |
| 금 | FDR `GC=F` | 4,361.80 | **$/온스** | 08-10* |
| S&P 500 | KIS `FHKST03030100` ISCD=`SPX` | 7,753.11 | 지수 | 실시간(지연) |
| 나스닥 종합 | 〃 `COMP` | 26,605.36 | 지수 | 〃 |
| VIX | 〃 `VIX` | 15.54 | 지수 | 〃 |

\* **정정(2026-08-12 실측)**: FDR 일봉의 마지막 행은 종가가 아니라 진행 중 세션의
현재가다(10~12분 지연). 값은 실시간이고 날짜 라벨만 하루 전이다 —
`docs/superpowers/specs/2026-08-12-index-section-design.md` 실측 1 참조.

재무부 XML은 매 영업일 ~15:47 UTC(=익일 00:47 KST) 공시라, 한국 아침엔 항상 직전 미국장 값이 있다.

### 버린 후보와 이유 (재조사 방지)

- **FRED**: DGS10은 되지만 최신 관측이 08-07 — 나흘 지연. WTI(`DCOILWTICO`)는 08-03로 일주일 지연,
  금 시리즈는 봇 차단. **마스터 기각: "8월 7일이면 의미가 없어보여"**
- **ETF 프록시(GLD $402·USO $126·TLT $82)**: KIS로 실시간 조회는 되지만 **단위가 다르다**.
  실제 금은 온스당 3,9xx~4,3xx달러 — "금 402"는 틀린 숫자로 읽힌다.
- **KIS 해외선물(진짜 WTI·금)**: KIS 자체 마스터(`ffcode.mst`)의 정확한 코드로 검증 —
  `CLU26` → `EGW00551 NYMEX SUB거래소 신청 계좌가 아닙니다`,
  `GCQ26` → `EGW00553 COMEX SUB거래소...`. **파라미터가 아니라 권한.**
  마스터가 NYMEX/COMEX를 신청하면 이 코드 그대로 승격 가능(설계에 승격 자리를 남긴다).
- **KIS 해외지수 TR의 함정**: 이 TR은 주식 티커도 받는다(AAPL 308.26, MSFT 506.06 확인).
  그래서 `CL`=93.15는 WTI가 아니라 **콜게이트**, `USB`=64.19는 **U.S. Bancorp**,
  `XAU`=370.93은 금광주 지수다. `DJI`·`TNX`·`GC`·`GOLD`는 0.00(미지원).
  **값이 0이 아니라고 그 상품이 아니다** — 단위 검증 없이 코드를 늘리지 말 것.
- **stooq**: xauusd·cl.f 전부 404.

## 설계

### 모듈 경계

```
backend/flow/worldidx.py     — 세 원천 fetch/parse/캐시 + 집계 (신규, 네트워크 담당)
backend/api/app.py           — GET /api/worldidx (신규 라우트 한 줄)
backend/report/dashboard.py  — '글로벌' 접힌 섹션 렌더 (기존 파일에 섹션 추가)
```

`worldidx.py` 하나로 묶는 이유: `futures.py`·`semi.py`와 같은 결(한 주제 = 한 모듈).
원천이 셋이지만 소비자가 보는 건 "칩 목록" 하나다.

### 공개 인터페이스

```python
async def get_worldidx() -> dict
# {"asof": "2026-08-11T21:40:00+09:00",
#  "groups": [{"label": "미국 금리", "items": [Item, ...]}, ...]}
# Item = {"key","label","value":float,"unit":"%"|"$/bbl"|"$/oz"|"idx",
#         "rate":float|None,"sign":"up"|"down"|"flat","basis":"08-10","src":"treasury"}
```

- `unit`을 **데이터에 실어** 내린다. 프런트가 단위를 추측하면 이번 조사에서 걸러낸
  프록시 사고가 그대로 재발한다.
- `basis`(기준일)도 **항목마다** 싣는다. 살아 있는 코스피 칩 옆에 놓이면 값이 신선해 보이므로,
  칩 자체에 기준일이 찍혀야 한다.

### 캐시·실패 처리

| 원천 | TTL | 실패 시 |
|---|---|---|
| 재무부 XML | 1시간 | 그 그룹만 생략 |
| FDR (`CL=F`,`GC=F`) | 10분 | 〃 |
| KIS 지수 | 60초 | 〃 |

**한 원천이 죽어도 나머지는 뜬다** — 대시보드 칩 스트립의 기존 원칙과 같다
("두 API 모두 실패에 관대해야 한다"). 전부 실패면 섹션을 통째로 감춘다(빈 껍데기 금지).
FDR·재무부는 동기 라이브러리/HTTP라 `asyncio.to_thread`로 감싸 이벤트 루프를 막지 않는다.

### 화면

대시보드에 접힌 `<details>` 섹션 "글로벌"을 추가한다(마스터 선택: 지수 섹션 추가).
칩 스트립(`#market`)은 이미 코스피·선물·환율로 차 있어 더 늘리면 가로로 넘친다.

```
▸ 글로벌            미국채 10Y 4.72% · WTI $82.13 · 금 $4,361.80   (접힘 상태 요약)
  ── 미국 금리 ──  2년 4.25%  10년 4.72%  30년 5.25%     기준 08-10
  ── 원자재 ──     WTI $82.13/배럴  금 $4,361.80/온스     기준 08-10
  ── 해외지수 ──   S&P500 7,753.11  나스닥 26,605.36  VIX 15.54
```

기존 `.mchip` 클래스를 재사용한다(새 디자인 언어를 만들지 않는다 — theme.py 단일 출처 원칙).

### 테스트

- 파서 단위 테스트: 재무부 XML 픽스처(실응답 저장) → 2Y/10Y/30Y 추출, 마지막 엔트리 선택
- 단위 보존 테스트: `unit`이 항목마다 실리고 `%`/`$/bbl`/`$/oz`가 섞이지 않는지
- 실패 격리 테스트: 한 원천이 예외를 던져도 나머지 그룹이 반환되는지
- 렌더 테스트: 섹션 HTML에 기준일이 항목마다 찍히는지
- 전부 오프라인(픽스처) — CI는 네트워크를 안 탄다
